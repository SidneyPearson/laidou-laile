# 行程与足迹体验问题修复验收

日期：2026-09-13。承接 `2026-09-12-two-round-user-experience.md` 中已获用户授权的五项问题。本轮仅修改本地前端；保留原有未提交工作，未提交、推送、部署或写生产数据库。

## 已完成

1. **切城保留打卡进度**：行程按城市分别保存，首页、探索、收藏和我的页面切城不再清空行程。切回后恢复已到地点、下一站及开始时间；主动清空或重新开始仅影响当前城市。旧版单城市存档在读取时兼容，下一次操作保存为多城市格式。此前已被旧逻辑清掉的进度无法凭空恢复。
2. **误打卡可撤销**：打卡后提供 8 秒快捷撤销；已到地点卡片始终提供“改为未到”。撤销只取消所选地点，将它恢复为下一站，其余打卡保留。滚动后的提示置于顶部栏下方，避免小屏遮挡。
3. **足迹与票根同步更正**：撤销完成行程后，关联的完成记录与新格式票根标记为已更正，不再用于点亮城市；保留记录并在票根列表说明原因。重新完成后可再次点亮、生成票根。其他历史行程不受影响；无法确切关联的旧票根不猜测删除。
4. **探索加载不误报空库**：城市信息与地点请求统一展示加载状态，请求未结束时不显示“0 个地点”空态。失败后提供重试，离开页面后忽略晚到请求，避免污染当前城市状态。
5. **时长与强度说明一致**：行程强度采用“轻松、适中、偏满、较紧”，不再混用“城市特种兵”画像名称；强度条与时长、地点数、直线跨度一致。停留时长明确不含交通和休息，直线距离不冒充导航距离。首页详情共用加入前的预计总停留时长提示，查询对应城市计划而不切换当前城市。
