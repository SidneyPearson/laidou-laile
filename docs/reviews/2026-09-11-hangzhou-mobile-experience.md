# 杭州移动端全流程体验

> 本文为修复前体验记录。后续用户已同意修改，并要求首页背景独立生成（覆盖下表旧的复用背景建议）。最新结果见 [移动端修复记录](2026-09-12-mobile-fixes.md)。

体验环境：本地 http://localhost:9090/，Computer Use，390×844 手机尺寸。通过界面点击、滑块拖动及选点卡片提供的键盘无障碍操作完成。不是手机触屏或微信真机验收；高德 App 唤起、微信相册与系统分享未验收。测试跨会话继续，浏览器会话恢复后已选的杭州行程仍在。

## 实际走过的流程

1. 首页点击当前城市 → 选择热门城市 → 搜索杭州 → 选中杭州。城市、天气和推荐地点更新，仍停留首页。
2. 选择“自由” → 启动探索 → 查看5个匹配地点。点击西湖卡片标题没有打开详情；通过卡片的加入操作选择西湖、西溪、清河坊。
3. 点击“差不多了”进入今日计划。3站显示约12.5小时，并提醒删一站。
4. 点击“帮我顺一下” → 预览西湖、清河坊、西溪顺序 → 采用建议，地点顺序及地图编号更新。
5. 打开西湖详情 → 收藏 → “就去这里” → 网页导航。新页面打开高德，目的地是“杭州西湖风景名胜区-断桥残雪”，原应用保留。未验证真实起点或实际道路导航。
6. 移出西溪 → 2站、约8.5小时。开始今天 → 模拟西湖到过 → 进度50%、下一站清河坊 → 模拟第二站到过 → 全部完成。
7. 生成杭州城市票根，地图与2张地点卡片出现。点击保存图片后持续停在“正在生成…”，后续多次查看仍未完成，未看到下载成功；没有向他人分享。
8. 关闭预览 → 我的 → 我的城市票根 → 回看成功；足迹地图点亮杭州；收藏页能找到西湖。
9. 回到首页，实际拖动探索滑块触发“重新开始一轮推荐？”；取消后保留原计划，滑块恢复，保护有效。

## 我的判断

主要路径能用，选点、排序、行程进度、票根回看形成了完整链条。现在的优先级应是修复保存与城市/画像一致性，再优化选点决策和视觉连贯性。

| 优先级 | 实际观察 | 建议 |
| --- | --- | --- |
| 高 | 票根保存持续“正在生成…”，没有明确失败、取消或完成结果；预览和历史记录本身正常。 | 图片加载和生成加超时、失败降级、可重试反馈。源码中的 loadCover/loadImageUrl 只等待 load/error，没有超时；这是可见风险，尚未确定本次卡住的具体请求。不要把“已生成票根记录”当成“图片已保存”。 |
| 高 | 已选杭州，但首页仍是上海天际线，图片替代文字却称“杭州封面”。代码 HomeHero 的 heroUrl 固定取 homepageAssets.hero。 | 使用已有杭州城市封面，保持名称、背景、天气、推荐一致；不能只改替代文字。 |
| 中 | 首页与“我的”显示“自由”，地点详情写“为什么适合懒人”，票根与历史列表写“懒人模式/懒人”。 | 统一对用户显示的画像名称；内部旧枚举不必跟随改动。 |
| 中 | “自由慢游”连续推荐西湖4–8小时、西溪3–5小时；可轻易选满3站，直到计划页才提醒12.5小时。 | 在选点阶段同步累计时长，第二个半日型景区加入时就提示取舍；保留当前已有的计划页强度提醒。 |
| 中 | 西湖详情以整个景区描述，地址较长；直到导航选择才出现具体的“断桥残雪”。 | 详情提前展示“建议从断桥残雪开始”，解释大景区与导航落点的关系，减少用户怀疑导航错位。 |
| 中 | 搜索结果说“进入城市探索”，点击后实际只换首页城市；点当前城市还要经过位置选择再进城市列表。 | 让按钮文案准确描述动作；手动换城市尽量直接进入选择列表。 |
| 中 | 选点卡片只写左右滑动，画面上没有明确的加入/跳过按钮，点标题不打开详情；说明文字在390px上偏小。 | 增加可点击的加入、跳过及详情入口，手势作为快捷方式；重点信息不应只藏在小字号和手势里。 |
| 低 | 首页、探索和收藏以黑色荧光色为主；今日计划大面积暖白和绿色，切换时风格变化明显。票根写“今日收藏完成”，与真正收藏含义冲突。 | 保持主按钮、底色和状态色更一致；票根用“今日行程完成”或“已完成2站”。 |

## 做得好的部分

- 地点照片足够醒目，地图和计划对应关系容易理解。
- 排序先预览、再采用；保留原顺序与恢复入口，不会悄悄更改用户选择。
- 过满行程有累计时长和明确提醒，不是只给一个地点数量。
- 进行中清楚突出下一站；标记到过后自动推进，完成票根有收尾感。
- 收藏、历史票根和足迹地图能相互承接；重新开始推荐会保护已有计划。

## 本轮边界

没有改产品代码、没有写生产数据库、没有部署。没有重新跑源码测试，因为本轮只做体验和记录。图片生成卡住与真机相册保存是不同问题，不能混为一项已完成验收。

本地浏览器里留下本次模拟数据：杭州2站已完成计划、1张杭州票根、1个西湖收藏；“到过”是流程测试，不是真实出行记录。其他用户/Agent工作区改动未清理。
